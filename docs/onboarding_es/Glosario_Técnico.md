# Glosario Técnico: Logística y Tecnología

Este glosario te ayudará a navegar las conversaciones técnicas con el equipo de desarrollo y con los clientes que tienen infraestructuras complejas.

## Conceptos de Negocio
- **Middleware:** Software que actúa como "puente" entre dos sistemas que no pueden comunicarse directamente.
- **Sistemas Legados (Legacy Systems):** Sistemas antiguos que siguen siendo el corazón de una empresa (ej. AS400, IBM i). Suelen ser difíciles de integrar con tecnología moderna.
- **Pérdida de Datos (Data Leak):** Información valiosa capturada en el campo (voces, fotos) que se pierde porque no puede ser introducida en el sistema antiguo de forma sencilla.
- **Doble Entrada de Datos:** El proceso manual en el que un empleado debe escribir en papel o en una app lo que un conductor ya dijo o hizo, y luego escribirlo de nuevo en la computadora.
- **Egresos (Egress):** El proceso de enviar los datos finalizados desde nuestra plataforma hacia el sistema del cliente (normalmente vía FTP/SFTP).

## Conceptos de Tecnología
- **IA (Inteligencia Artificial):** Tecnología que usamos para "entender" el lenguaje natural de los conductores y extraer datos útiles de él.
- **LLM (Large Language Model):** El tipo de IA (como Claude o Gemma) que usamos para procesar el lenguaje.
- **API (Application Programming Interface):** El "contrato" o canal de comunicación por el cual nuestra app móvil habla con nuestro servidor.
- **JSON:** El formato estándar de texto que usan los sistemas para intercambiar datos de manera estructurada.
- **Latitud/Longitud (GPS):** Coordenadas geográficas exactas que usamos para rastrear la ubicación del conductor.
- **Entidades:** Datos específicos que extraemos (ej. nombre del cliente, código de puerta, ubicación exacta).
